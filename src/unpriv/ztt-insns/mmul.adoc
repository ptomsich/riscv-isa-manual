[#insns-mmul,reftext="Matrix Elementwise Multiply"]
==== insn:mmul[]

Synopsis::
Elementwise multiply

Mnemonic::
insn:mmul[_md_._td_, _ms1_._t1_, _ms2_._t2_[, _rm_\][, sat\]] +
insn:mmul[_md_._td_, _ms1_._t1_, _rs2_[, _rm_\][, sat\]] +
insn:mmul[_md_._td_, _ms1_._t1_, _imm_[, _rm_\][, sat\]] +
insn:mmul[_accd_._td_, _accs_._t1_, _acc2_._t2_[, _rm_\][, sat\]] +
insn:mmul[_accd_._td_, _accs_._t1_, _rs2_[, _rm_\][, sat\]] +
insn:mmul[_accd_._td_, _accs_._t1_, _imm_[, _rm_\][, sat\]] +

Description::
[#norm:mmul_op]#insn:mmul[] writes _a_ {times} _b_ to each element of the destination, for the corresponding elements _a_ of the first source and _b_ of the second (<<ztt-ops-arith>>).
A scalar operand supplies _b_ for every element (<<ztt-ops-elementwise>>), and a broadcast operand for every element of a column or of a row (<<ztt-ops-acc>>).#
+
[#norm:mmul_types]#The operands have one datatype.
On matrix registers, each an _N_ {times} RLEN/__w__ matrix, it is an integer datatype or a floating-point datatype other than E8M0 and TF32; on accumulator registers, it is INT32, UINT32, or FP32.#
+
[#norm:mmul_round]#A floating-point product is rounded as selected by `rm` and saturated as selected by `sat`, and the floating-point exception flags accrue in csr:fflags[].
An integer product wraps or saturates as selected by `sat`.#

Exceptions::
[#norm:mmul_illegal]#_Illegal Instruction_ is raised if any of the following conditions holds:#
+
* csr:mstatus[ts] is Off, or V=1 and csr:vsstatus[ts] is Off.
* _td_ is a floating-point datatype, and ext:f[] is not implemented, or csr:mstatus[fs] is Off, or V=1 and csr:vsstatus[fs] is Off.
* _td_ is FP64 and ext:d[] is not implemented.
* _td_, _t1_, and _t2_ are not one datatype that insn:mmul[] supports for its operands, or name a reserved type code.
* `form` is not listed for `a`.
* `a` is set, and ext:zttc[] is not implemented or the register number of an accumulator operand is not less than _R_.
* `form` is 001 and the element width is greater than XLEN, or `form` is 010 and _td_ is a floating-point datatype.
* `form` is 110 or 111, and ext:zttg[] is not implemented or _ms2_ is odd.
* _td_ is an integer datatype and `rm` is not 0.
* _td_ is a floating-point datatype and `rm` is reserved, or `rm` is DYN and csr:frm[] holds a reserved value.
* `sat` is 0 and reserved for the datatype (<<ztt-saturation>>).
* A reserved field, bits 38:37 without an immediate or bits 63:61, is not 0.

Operation::
[source,sail]
--
mapping clause encdec64 = MMUL(a, md, ms1, f2, td, rm, sat, t1, t2, form, s2, ih)
  <-> s2 @ form @ t2 @ t1 @ sat @ rm @ td @ ih @ ZTT_ZLMAJ @ 0b11
    @ 0b000010 @ a @ f2 @ ms1 @ 0b100 @ md @ ZTT_ZLOP @ 0b11111

function clause execute MMUL(a, md, ms1, f2, td, rm, sat, t1, t2, form, s2, ih) = {
  if not(ztt_enabled()) then return Illegal_Instruction();
  /* A floating-point datatype needs F, D for FP64, and FS. */
  if not(ztt_fp_enabled(td)) then return Illegal_Instruction();
  /* One datatype of the arithmetic operations: an integer datatype or a floating-point
     datatype other than E8M0 and TF32; INT32, UINT32, or FP32 on accumulators. */
  if t1 != td | t2 != td | not(ztt_ew_arith_type(a, td)) then return Illegal_Instruction();
  if not(mmul_form(a, form)) then return Illegal_Instruction();
  /* An operand is one matrix register or, with a set, an accumulator register;
     ztt_ew_operand returns None() for an accumulator operand without Zttc and for
     an accumulator register number of R or more.  f2 and ih hold the second source;
     ztt_ew_source2 returns None() for a scalar wider than XLEN, a floating-point
     immediate, a slot index out of range, a group without Zttg or one that is not
     aligned, and a reserved field that is not 0. */
  let dst  : option(ztt_operand) = ztt_ew_operand(a, md, td);
  let src1 : option(ztt_operand) = ztt_ew_operand(a, ms1, t1);
  let src2 : option(ztt_source2) = ztt_ew_source2(a, form, f2, ih, t2, s2);
  if dst == None() | src1 == None() | src2 == None() then return Illegal_Instruction();
  if not(ztt_sat_valid(t1, td, sat)) then return Illegal_Instruction();
  let rmd : option(ztt_rounding) = ztt_rounding_mode(t1, td, rm);   /* DYN reads frm */
  if rmd == None() | (ztt_is_int(td) & rm != 0b000) then return Illegal_Instruction();

  let N = ztt_N();
  /* A matrix register holds RLEN/w columns, and an accumulator register N. */
  let C = if a == 0b1 then N else ztt_RLEN() / ztt_type_width(td);
  let x = ztt_read_operand(the(src1), N, C);
  /* A scalar operand is every element; a row broadcast has v[c] in element (r, c),
     and a column broadcast v[r]. */
  let y = ztt_read_source2(the(src2), N, C);
  var flags : bits(5) = zeros();
  foreach (r from 0 to (N - 1)) {
    foreach (c from 0 to (C - 1)) {
      let (e, f) = ztt_mul(td, ztt_element(x, r, c), ztt_element(y, r, c), the(rmd), sat);
      ztt_write_element(the(dst), r, c, e);
      flags = flags | f;
    }
  };
  accrue_fflags(flags);
  ztt_set_dirty();
  RETIRE_SUCCESS
}

function mmul_form(a : bits(1), form : bits(3)) -> bool =
  match (a, form) {
    (_,   0b000) => true,    /* a register of the class of the destination */
    (_,   0b001) => true,    /* X register */
    (_,   0b010) => true,    /* immediate */
    (0b1, 0b110) => true,    /* row broadcast */
    (0b1, 0b111) => true,    /* column broadcast */
    _            => false
  }
