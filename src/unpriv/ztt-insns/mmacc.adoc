<<<
[#insns-mmacc,reftext="Matrix Multiply-Accumulate"]
==== insn:mmacc[] and insn:mmacc.n[]

Synopsis::
Matrix multiply-accumulate

Mnemonic::
insn:mmacc[_md_._td_, _ms1_``x``__G1__._t1_, _ms2_``x``__G2__._t2_[, _rm_\][, sat\]] +
insn:mmacc.n[_md_._td_, _ms1_``x``__G1__._t1_, _ms2_``x``__G2__._t2_[, _rm_\][, sat\]]
+
``x``__G__ is omitted for _G_ = 1.

Arguments::

[%autowidth]
[%header,cols="4,2,2"]
|===
|Register
|Direction
|Definition

| _ms1_ | input | A, a group of _G1_ matrix registers of datatype _t1_
| _ms2_ | input | B, a group of _G2_ matrix registers of datatype _t2_
| _md_ | input and output | C, an accumulator register or pair of datatype _td_
|===

Column Field::
[#norm:mmacc_kc]#`kc` gives _K_ = 2^`kc`^{nbsp}{times}{nbsp}__N__, the number of columns of both sources.
Source _i_, of element width _w~i~_, occupies _Gi_ = 2^`kc`^{nbsp}{times}{nbsp}__w~i~__/16 registers.#
+
* For sources of one element width, _G1_ = _G2_.
* In a mixed-width multiply, the narrower source occupies the smaller group: _G1_/_G2_ = _w~1~_/_w~2~_.
* Sources wider than 16 bits hold exactly _N_ columns, so `kc` is 0 for TF32 and FP32, and _G_ = _w_/16.
* insn:mmacc[] and insn:mmacc.n[] take no slot index, so each _Gi_ is 1, 2, or 4.
+
.Values of `kc` and the resulting group sizes.
[%autowidth,float="center",align="center",cols=">,>,^,^,^,^,^",options="header"]
|===
|`kc` |_K_ |2-bit |4-bit |8-bit |16-bit |32-bit
|0 |_N_ |– |– |– |1 |2
|1 |2__N__ |– |– |1 |2 |–
|2 |4__N__ |– |1 |2 |4 |–
|3 |8__N__ |1 |2 |4 |– |–
|4 |16__N__ |2 |4 |– |– |–
|5 |32__N__ |4 |– |– |– |–
|===
+
A 64-bit source (<<ztt-ext-acc64>>) occupies four registers with `kc` = 0.
In assembly, `kc` follows from the group suffixes of the sources, which must give both the same number of columns.

Description::
[#norm:mmacc_op]#insn:mmacc[] computes C {leftarrow} C + A {times} B^T^, and insn:mmacc.n[] computes C {leftarrow} C + A {times} B, as specified in <<ztt-ops-mmacc>>.#
A is the _N_ {times} _K_ matrix held by _ms1_, and the operand of _ms2_ holds _K_ columns, read as B^T^ for insn:mmacc[] and as B for insn:mmacc.n[] (<<ztt-ops-mmacc>>).
+
[#norm:mmacc_int]#For integer datatypes, C is replaced by the exact sum of C and the products, reduced modulo 2^__n__^.#
[#norm:mmacc_fp]#For floating-point datatypes, C is computed as specified in <<ztt-matmul-numerics>>, rounded as selected by `rm` and saturated as selected by `sat`, and the floating-point exception flags accrue in csr:fflags[].#

Exceptions::
[#norm:mmacc_illegal]#_Illegal Instruction_ is raised if any of the following conditions holds:#
+
* csr:mstatus[ts] is Off, or V=1 and csr:vsstatus[ts] is Off.
* The combination of _t1_, _t2_, and _td_ is not supported (<<ztt-mmacc-table>>, <<ztt-acc64-table>>), or names a reserved type code.
* `kc` is greater than 5, or a source's _G_ is not 1, 2, or 4, is not valid for its datatype, or names a group that is not aligned (<<ztt-groups>>).
* _md_ is not less than _R_, or _td_ is a 64-bit datatype and _md_ is odd.
* _td_ is an integer datatype and `rm` or `sat` is not 0.
* _td_ is a floating-point datatype and `rm` is reserved, or `rm` is DYN and csr:frm[] holds a reserved value.
* A reserved field, bits 38:37 or 63:61, is not 0.

Operation::
[source,sail]
--
mapping clause encdec64 = MMACC(form, md, ms1, ms2, td, rm, sat, t1, t2, kc)
  <-> 0b000 @ kc @ t2 @ t1 @ sat @ rm @ td @ 0b00 @ ZTT_ZLMAJ @ 0b11
    @ mmacc_op(form) @ ms2 @ ms1 @ 0b001 @ md @ ZTT_ZLOP @ 0b11111

function clause execute MMACC(form, md, ms1, ms2, td, rm, sat, t1, t2, kc) = {
  /* Every check depends only on the encoding, R and frm. */
  if not(ztt_enabled()) then return Illegal_Instruction();
  if not(ztt_mmacc_supported(t1, t2, td)) then return Illegal_Instruction();
  if unsigned(kc) > 5 then return Illegal_Instruction();
  /* G = 2^kc * w / 16; G < 1 would be a slot, which mmacc does not take. */
  let s1 = 2 ^ unsigned(kc) * ztt_type_width(t1);
  let s2 = 2 ^ unsigned(kc) * ztt_type_width(t2);
  if s1 < 16 | s1 > 64 | s2 < 16 | s2 > 64 then return Illegal_Instruction();
  let G1 = s1 / 16;
  let G2 = s2 / 16;
  if not(ztt_group_valid(ms1, G1, t1) & ztt_group_valid(ms2, G2, t2))
  then return Illegal_Instruction();
  let N = ztt_N();
  let K = 2 ^ unsigned(kc) * N;
  if not(ztt_acc_valid(md, td)) then return Illegal_Instruction();

  if ztt_is_int(td) then {
    if rm != 0b000 | sat != 0b0 then return Illegal_Instruction();
    foreach (i from 0 to (N - 1)) {
      foreach (j from 0 to (N - 1)) {
        var c : int = ztt_read_acc_int(md, td, i, j);
        foreach (k from 0 to (K - 1)) {
          let (r, s) = mmacc_b_index(form, N, j, k);
          c = c + ztt_read_m_int(ms1, G1, t1, i, k) * ztt_read_m_int(ms2, G2, t2, r, s);
        };
        ztt_write_acc_int(md, td, i, j, c);   /* reduced modulo 2^n */
      }
    }
  } else {
    let rm_3b = if rm == 0b111 then fcsr[FRM] else rm;
    match ztt_fp_rounding_mode(rm_3b) {
      None()    => return Illegal_Instruction(),
      Some(rmd) => {
        var flags : bits(5) = zeros();
        foreach (i from 0 to (N - 1)) {
          foreach (j from 0 to (N - 1)) {
            /* The model of ztt-matmul-numerics, with the disclosed (P, psm, rnd). */
            let (c, f) = ztt_fp_mm_element(form, md, ms1, ms2, G1, G2, td, t1, t2,
                                           i, j, K, rmd, sat);
            ztt_write_acc(md, td, i, j, c);
            flags = flags | f;
          }
        };
        accrue_fflags(flags);
      }
    }
  };
  ztt_set_dirty();
  RETIRE_SUCCESS
}

mapping mmacc_op : mmacc_form <-> bits(7) = {
  MMACC_ABT <-> 0b0000000,
  MMACC_AB  <-> 0b0000001
}

/* Element (k, j) of the multiplier is element (r, s) of the operand of ms2. */
function mmacc_b_index(form : mmacc_form, N : int, j : int, k : int) -> (int, int) =
  match form {
    MMACC_ABT => (j, k),
    MMACC_AB  => (k % N, (k / N) * N + j)
  }
