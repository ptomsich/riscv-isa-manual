<<<
[#insns-madd,reftext="Matrix Elementwise Add"]
==== insn:madd[]

Synopsis::
Elementwise add

Mnemonic::
insn:madd[_md_._td_, _ms1_._t1_, _ms2_._t2_[, _rm_\][, sat\]] +
insn:madd[_md_._td_, _ms1_._t1_, _rs2_[, _rm_\][, sat\]] +
insn:madd[_md_._td_, _ms1_._t1_, _imm_[, _rm_\][, sat\]] +
insn:madd[_accd_._td_, _accs_._t1_, _acc2_._t2_[, _rm_\][, sat\]] +
insn:madd[_accd_._td_, _accs_._t1_, _ms2_``x``__G__._t2_[, _rm_\][, sat\]] +
insn:madd[_accd_._td_, _accs_._t1_, _ms2_[_s2_\]._t2_[, _rm_\][, sat\]] +
insn:madd.row[_accd_._td_, _accs_._t1_, _ms2_``x2``._t2_[, _rm_\][, sat\]] +
insn:madd.col[_accd_._td_, _accs_._t1_, _ms2_``x2``._t2_[, _rm_\][, sat\]]
+
A matrix-register operand that is added to an accumulator holds a tile: ``x``__G__ is `x2` for a 32-bit datatype and omitted for a 16-bit datatype, and a narrower datatype is written with its slot index, also for slot 0.

Description::
[#norm:madd_op]#insn:madd[] writes _a_ + _b_ to each element of the destination, for the corresponding elements _a_ of the first source and _b_ of the second (<<ztt-ops-arith>>).
A scalar operand supplies _b_ for every element (<<ztt-ops-elementwise>>), and a broadcast operand for every element of a column or of a row (<<ztt-ops-acc>>).#
+
[#norm:madd_types]#On matrix registers, each an _N_ {times} RLEN/__w__ matrix, the operands have one datatype: an integer datatype, or a floating-point datatype other than E8M0 and TF32.
On accumulator registers, the destination and the first source have one datatype, INT32, UINT32, or FP32, which is also that of a second source in an accumulator register and of a broadcast operand.#
+
[#norm:madd_tile]#A tile in matrix registers has a datatype that converts exactly to that of the accumulator (<<ztt-exact-table>>): each of its elements is converted, and the sum is rounded once.#
+
[#norm:madd_round]#A floating-point sum is rounded as selected by `rm` and saturated as selected by `sat`, and the floating-point exception flags accrue in csr:fflags[].
An integer sum wraps or saturates as selected by `sat`.#

Exceptions::
[#norm:madd_illegal]#_Illegal Instruction_ is raised if any of the following conditions holds:#
+
* csr:mstatus[ts] is Off, or V=1 and csr:vsstatus[ts] is Off.
* _td_ is a floating-point datatype, and ext:f[] is not implemented, or csr:mstatus[fs] is Off, or V=1 and csr:vsstatus[fs] is Off.
* _td_ is FP64 and ext:d[] is not implemented.
* _td_ and _t1_ are not one datatype that insn:madd[] supports for its operands, or a type code is reserved.
* _t2_ is not _td_, or with `form` = 100 does not convert exactly to it.
* `form` is not listed for `a`.
* `a` is set, and ext:zttc[] is not implemented or the register number of an accumulator operand is not less than _R_.
* `form` is 001 and the element width is greater than XLEN, or `form` is 010 and _td_ is a floating-point datatype.
* The second source is a tile of a 32-bit datatype or a broadcast operand, and ext:zttg[] is not implemented or _ms2_ is odd.
* `s2` is 16/__w__ or more for a tile of element width _w_ < 16, or is not 0 otherwise.
* _td_ is an integer datatype and `rm` is not 0.
* _td_ is a floating-point datatype and `rm` is reserved, or `rm` is DYN and csr:frm[] holds a reserved value.
* `sat` is 0 and reserved for the datatype (<<ztt-saturation>>).
* Bits 38:37 are not 0 without an immediate.

Operation::
[source,sail]
--
mapping clause encdec64 = MADD(a, md, ms1, f2, td, rm, sat, t1, t2, form, s2, ih)
  <-> s2 @ form @ t2 @ t1 @ sat @ rm @ td @ ih @ ZTT_ZLMAJ @ 0b11
    @ 0b000000 @ a @ f2 @ ms1 @ 0b100 @ md @ ZTT_ZLOP @ 0b11111

function clause execute MADD(a, md, ms1, f2, td, rm, sat, t1, t2, form, s2, ih) = {
  if not(ztt_enabled()) then return Illegal_Instruction();
  /* A floating-point datatype needs F, D for FP64, and FS. */
  if not(ztt_fp_enabled(td)) then return Illegal_Instruction();
  /* The destination and the first source have one datatype of the arithmetic
     operations: an integer datatype or a floating-point datatype other than E8M0 and
     TF32; INT32, UINT32, or FP32 on accumulators.  A tile converts exactly to it. */
  if t1 != td | not(ztt_ew_arith_type(a, td)) then return Illegal_Instruction();
  if not(t2 == td | (form == 0b100 & ztt_converts_exactly(t2, td)))
  then return Illegal_Instruction();
  if not(madd_form(a, form)) then return Illegal_Instruction();
  /* An operand is one matrix register or, with a set, an accumulator register;
     ztt_ew_operand returns None() for an accumulator operand without Zttc and for
     an accumulator register number of R or more.  f2 and ih hold the second source;
     ztt_ew_source2 returns None() for a scalar wider than XLEN, a floating-point
     immediate, a slot index out of range, a group without Zttg or one that is not
     aligned, and a reserved field that is not 0. */
  let dst  : option(ztt_operand) = ztt_ew_operand(a, md, td);
  let src1 : option(ztt_operand) = ztt_ew_operand(a, ms1, t1);
  let src2 : option(ztt_source2) = ztt_ew_source2(a, form, f2, ih, t2, s2);
  if dst == None() | src1 == None() | src2 == None() then return Illegal_Instruction();
  if not(ztt_sat_valid(t1, td, sat)) then return Illegal_Instruction();
  let rmd : option(ztt_rounding) = ztt_rounding_mode(t1, td, rm);   /* DYN reads frm */
  if rmd == None() | (ztt_is_int(td) & rm != 0b000) then return Illegal_Instruction();

  let N = ztt_N();
  /* A matrix register holds RLEN/w columns, and an accumulator register N. */
  let C = if a == 0b1 then N else ztt_RLEN() / ztt_type_width(td);
  let x = ztt_read_operand(the(src1), N, C);
  /* A scalar operand is every element; a row broadcast has v[c] in element (r, c),
     and a column broadcast v[r].
     A tile is a slot, one register, or a group of two, by the width of t2. */
  let y = ztt_read_source2(the(src2), N, C);
  var flags : bits(5) = zeros();
  foreach (r from 0 to (N - 1)) {
    foreach (c from 0 to (C - 1)) {
      /* An element of a tile is converted exactly; the sum is rounded once. */
      let b = ztt_convert_exact(td, t2, ztt_element(y, r, c));
      let (e, f) = ztt_add(td, ztt_element(x, r, c), b, the(rmd), sat);
      ztt_write_element(the(dst), r, c, e);
      flags = flags | f;
    }
  };
  accrue_fflags(flags);
  ztt_set_dirty();
  RETIRE_SUCCESS
}

function madd_form(a : bits(1), form : bits(3)) -> bool =
  match (a, form) {
    (_,   0b000) => true,    /* a register of the class of the destination */
    (0b0, 0b001) => true,    /* X register */
    (0b0, 0b010) => true,    /* immediate */
    (0b1, 0b100) => true,    /* tile in matrix registers */
    (0b1, 0b110) => true,    /* row broadcast */
    (0b1, 0b111) => true,    /* column broadcast */
    _            => false
  }
